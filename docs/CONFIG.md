# ⚙️ ตั้งค่า (config.env)

โหลดอัตโนมัติจาก `config.env` (หรือ `.env`) ในโฟลเดอร์ที่รันไบนารี

## จำเป็น

| ตัวแปร | ตัวอย่าง | หมายเหตุ |
|--------|----------|----------|
| `DISCORD_TOKEN` | `MTIz...` | เว้นว่าง = dry-run |
| `GUILD_ID` | `1234567890` | เซิร์ฟเวอร์ที่จะทำงาน |
| `LOBBY_CHANNEL_ID` | `1234567890` | ห้องพักคนที่ยังไม่เข้าโซน (ปิดไมค์อัตโนมัติ) |

## Discord

| ตัวแปร | ค่าเริ่มต้น | หมายเหตุ |
|--------|-------------|----------|
| `CATEGORY_ID` | – | หมวดที่ใช้สร้างห้องโซน |
| `FIX_MIC_ID` / `ADMIN_CHANNEL_ID` | – | ห้องส่งแผงแก้ไมค์ + รับ `!menu` |
| `API_SECRET` | `mcpe-voice-secret-zirconx` | ต้องตรงกับในเกม |

## HTTP

| ตัวแปร | ค่าเริ่มต้น | หมายเหตุ |
|--------|-------------|----------|
| `BIND_ADDR` | `0.0.0.0:3000` | ชนะ `PORT` ถ้าตั้งทั้งคู่ |
| `PORT` | `3000` | ทางลัด |

## การจัดห้อง

| ตัวแปร | ค่าเริ่มต้น | ผล |
|--------|-------------|-----|
| `ZONE_PREFIX` | `ห้องที่ ` | คำนำหน้าชื่อห้อง |
| `ZONE_LIMIT` | `100` | จำนวนห้องสูงสุดที่สร้าง |
| `SOLO_GRACE_PLANS` | `8` | อยู่คนเดียวกี่รอบก่อนกลับ Lobby |
| `ENTER_STREAK` | `2` | ต้องอยู่ในระยะติดกันกี่ครั้งถึงจะรวมห้อง |
| `EXIT_STREAK` | `3` | หลุดระยะติดกันกี่ครั้งถึงจะแยก |
| `RADIUS_MODE` | `max` | `max` = ใครกว้างถึงก็ได้ยิน, `min` = ต้องถึงทั้งคู่, `avg` = เฉลี่ย |
| `REQUIRE_VERIFIED` | `true` | คนที่ยังไม่ยืนยัน Discord ถูกข้าม |
| `MOVE_CONCURRENCY` | `3` | จำนวนย้ายพร้อมกัน (1–8) |

## ค่าที่แนะนำตามขนาดเซิร์ฟเวอร์

| ผู้เล่น | ENTER/EXIT | MOVE_CONCURRENCY | SOLO_GRACE_PLANS |
|---------|-----------|------------------|------------------|
| ≤ 10 | 2 / 3 | 2 | 8 |
| 11–30 | 2 / 3 | 3 | 6 |
| 31–60 | 3 / 4 | 4 | 5 |
